# Token aliases — remove in UI-2 Part H

Until Part H, Tailwind and CSS keep these legacy names as aliases. `mist` is a real token
(`#F4F6F8`) and is no longer an alias of `hover`.

| Legacy | Use instead |
|---|---|
| `cell-blue`, `cell-blue-deep`, `cell-blue-wash`, `cell-blue-tint`, `cell-blue-hover` | `blue`, `blue-deep`, `blue-wash`, `blue-press` |
| `graphite` | `ink-2` |
| `quiet` | `ink-3` |
| `ink-muted` | `ink-2` |
| `ink-subtle` | `ink-3` |
| `canvas` | `mist` or `paper` |
| `surface-hover` | table row hover (`#FAFBFC`) |
| `max-w-workspace`, `max-w-hive` | `max-w-content` / `col-read` / `col-wide` per page |
| `rounded-card`, `rounded-composer` | `rounded-input` |
| `text-glance` | `text-state` |
| `font-mono` in UI (not code) | remove |
