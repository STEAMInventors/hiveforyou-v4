# Token aliases — remove in UI-1c

Until UI-1c, Tailwind and CSS keep these legacy names as aliases:

| Legacy | Use instead |
|---|---|
| `cell-blue`, `cell-blue-deep`, `cell-blue-wash`, `cell-blue-tint`, `cell-blue-hover` | `blue`, `blue-deep`, `blue-wash` |
| `graphite` | `ink-2` |
| `quiet` | `ink-3` |
| `ink-muted` | `ink-2` |
| `ink-subtle` | `ink-3` |
| `mist`, `surface-hover` | `hover` |
| `max-w-workspace`, `max-w-hive` | `col-read` / `col-wide` per page |
| `rounded-card` | `rounded-surface` |
| `font-mono` in UI (not code) | remove |
